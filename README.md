# ⏱️ Time Calculator
A simple and practical web application for calculating total working hours across multiple time intervals.

Time Calculator allows users to enter their arrival and departure times and easily calculate their total working duration.
### ✨ Features
* Add multiple time intervals.
* Calculate total working hours and minutes.
* Support for overnight time intervals.
* Remove individual time intervals.
* Clear all entered intervals.
* Simple and user-friendly interface.

### 🛠️ Technologies
* HTML5
* CSS3
* JavaScript
* Tailwind CSS
